# Sona artwork

`sona-logo.png` is the transparent doughnut mark shared by the web app, Android companion and Electrobun icons. The desktop iconset and mobile `assets/icon.png` are resized PNG exports with the original alpha preserved.

The replacement mark was produced with the built-in image generation tool on 2026-11-16, using the existing Sona doughnut as the edit reference. Final selected prompt:

> Edit the supplied Sona doughnut logo into a clean application icon. Preserve the same glossy pink icing, golden dough, three pale yellow sprinkles, almost front facing perspective and centered circular silhouette. Remove all background residue, ground shadow and black tile. True transparent alpha outside the doughnut AND inside the hole, clean antialiased edges. Single large doughnut with modest 8% transparent margin on a square canvas. No text, no additional objects. Output ready for a standalone macOS dock icon.

The pixel artwork used by onboarding is separate from this mark.
